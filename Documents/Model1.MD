This notebook trains and evaluates the Logistic Regression model used for hospital readmission prediction.

---

## Purpose

The purpose of Model 1 is to establish an interpretable baseline model for predicting whether a patient will be readmitted within 30 days of discharge.

The model uses demographic, admission, transfer, service, and DRG-related features generated during preprocessing and feature engineering.

---

## Algorithm

### Logistic Regression

Logistic Regression is a supervised machine learning algorithm used for binary classification problems.

In this project the model predicts:

- 0 = Not readmitted within 30 days
- 1 = Readmitted within 30 days
