## Model 2

Notebook: model2_random_forest.ipynb

This notebook trains and evaluates the Random Forest model used for hospital readmission prediction.

## Purpose

The purpose of Model 2 is to develop a more powerful non-linear machine learning model capable of capturing complex relationships between patient characteristics, admission information, DRG indicators, service history, and transfer activity.

## Algorithm

### Random Forest Classifier

Random Forest is an ensemble learning algorithm that combines multiple decision trees to improve predictive performance and reduce overfitting.

In this project the model predicts:

- 0 = Not readmitted within 30 days
- 1 = Readmitted within 30 days

## Input File

The notebook requires:

model_dataset.csv

This file is generated by:

02_feature_engineering.ipynb

## Data Split

- Training Set = 80%
- Testing Set = 20%

A stratified train-test split is used.


## Data Preprocessing

### Numerical Features

- Median Imputation

### Categorical Features

- Most Frequent Imputation
- One-Hot Encoding
